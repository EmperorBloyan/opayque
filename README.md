# Opayque — Shielded Merchant Payment Infrastructure

Production-ready privacy-first payment system for merchants on Solana.

## Core Features
- MagicBlock TEE-shielded payments
- Merchant Vault + Staff Terminal
- Automated fiat settlements
- KYB/Compliance screening
- Secure wallet authentication + RLS

## Quick Start
1. `npm install`
2. Apply RLS policies in Supabase SQL Editor
3. `npm run dev`

## Security Notes
- Row Level Security enabled
- Rate limiting active
- Wallet signature verification

Built with Next.js + Anchor + MagicBlock + Supabase.
